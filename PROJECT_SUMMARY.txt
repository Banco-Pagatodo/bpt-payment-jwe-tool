┌───────────────────────────────────────────────────────────────────────────┐
│ 🎯 COMANDOS DISPONIBLES                                                   │
└───────────────────────────────────────────────────────────────────────────┘

 1️⃣  generate-keys
     Genera pares de llaves RSA (4096) y ECDSA (P-256)
     
     $ bpt-jwe generate-keys --output-dir ./keys

 2️⃣  configure
     Configura Client-ID y rutas a llaves
     
     $ bpt-jwe configure \
         --client-id "CLIENT_123" \
         --client-rsa-private "./keys/client-rsa-private.pem" \
         --client-ecdsa-private "./keys/client-ecdsa-private.pem" \
         --bank-rsa-public "./bank/bank-rsa-public.pem" \
         --bank-ecdsa-public "./bank/bank-ecdsa-public.pem"

 3️⃣  encrypt
     Cifra JSON a JWE para enviar al banco
     
     $ bpt-jwe encrypt --input ./request.json --output ./encrypted.txt

 4️⃣  decrypt
     Descifra JWE recibido del banco
     
     $ bpt-jwe decrypt --input ./response.txt

 ┌─────────────────────────────────────────────────────────────────────┐
 │ CIFRADO                                                             │
 ├─────────────────────────────────────────────────────────────────────┤
 │ • Algoritmo de clave: RSA-OAEP                                      │
 │ • Tamaño de llave RSA: 4096 bits                                    │
 │ • Algoritmo de contenido: AES-256-CBC-HMAC-SHA-512                  │
 └─────────────────────────────────────────────────────────────────────┘

 ┌─────────────────────────────────────────────────────────────────────┐
 │ FIRMA DIGITAL                                                       │
 ├─────────────────────────────────────────────────────────────────────┤
 │ • Algoritmo: ECDSA-SHA256                                           │
 │ • Curva elíptica: nistP256 (prime256v1)                             │
 └─────────────────────────────────────────────────────────────────────┘

 ┌─────────────────────────────────────────────────────────────────────┐
 │ ESTRUCTURA TOKEN                                                    │
 ├─────────────────────────────────────────────────────────────────────┤
 │ • Issuer: ClientId (request) / "PagaTodo" (response)                │
 │ • Audience: "PagaTodo" (request) / ClientId (response)              │
 │ • Expiración: 1 hora desde creación                                 │
 │ • Claim de datos: "data" con JSON stringificado                     │
 └─────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────────┐
│ 🔄 FLUJO DE DATOS                                                         │
└───────────────────────────────────────────────────────────────────────────┘

 REQUEST (Cliente → Banco):
 
   [Cliente crea JSON]
          ↓
   [CLI cifra con llave pública RSA del banco]
          ↓
   [CLI firma con llave privada ECDSA del cliente]
          ↓
   [Se genera JWE Token]
          ↓
   [Cliente envía a POST /bpt/cash-in o /bpt/cash-out]
          ↓
   [Banco descifra con su llave privada RSA]
          ↓
   [Banco verifica firma con llave pública ECDSA del cliente]


 RESPONSE (Banco → Cliente):
 
   [Banco genera respuesta JSON]
          ↓
   [Banco cifra con llave pública RSA del cliente]
          ↓
   [Banco firma con llave privada ECDSA del banco]
          ↓
   [Banco envía JWE Token]
          ↓
   [CLI descifra con llave privada RSA del cliente]
          ↓
   [CLI verifica firma con llave pública ECDSA del banco]
          ↓
   [Cliente obtiene JSON de respuesta]
